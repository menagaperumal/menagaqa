# Menaga Senraya Perumal — Portfolio Site

A single-page, static portfolio site. No build step, no dependencies — just `index.html`.

## Deploy free on GitHub Pages

1. Create a new **public** GitHub repository, e.g. `menaga-portfolio`
   (Settings > name it anything — this becomes part of your URL).
2. Upload these files to the repo root:
   - `index.html`
   - the `assets` folder (add `assets/photo.jpg` when you have your headshot)
3. Go to the repo's **Settings > Pages**.
4. Under "Build and deployment", set **Source** to `Deploy from a branch`,
   branch `main`, folder `/ (root)`. Click **Save**.
5. Wait ~1 minute, then your site is live at:
   `https://<your-github-username>.github.io/<repo-name>/`

That URL is what you put on LinkedIn (Contact Info > Website) and on your resume.

## Updating later

Any time you edit `index.html` (new job, new skill, etc.) and push the change,
GitHub Pages redeploys automatically within a minute or two.
