HOW TO ADD YOUR PROFILE PHOTO
==============================

1. Pick a professional, well-lit headshot (square works best, e.g. 500x500px or larger).
2. Rename the file exactly to:  photo.jpg
3. Place it in this "assets" folder, replacing nothing (there's no existing file yet).
4. Commit and push to GitHub (or drag-and-drop via GitHub's web UI) — the site will
   pick it up automatically. Until then, the site shows your initials "MP" instead.

If your photo is a .png or .jpeg instead of .jpg, either:
  a) rename it to photo.jpg, or
  b) open index.html and change this line:
        <img src="assets/photo.jpg" ...>
     to match your actual filename, e.g. assets/photo.png
